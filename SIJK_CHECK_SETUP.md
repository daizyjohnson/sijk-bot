# SIJK CHECK — тестовая ветка

Модуль пока **не предназначен для включения в production** без тестового запуска.
Ветка: `feature/sijk-check`. Не меняйте запуск Bothost на неё до проверки.

## Настройка Google Sheets

1. Создайте сервисный аккаунт в Google Cloud с доступом к Google Sheets API.
2. Поделитесь существующей таблицей с `client_email` сервисного аккаунта, уровень **Читатель**.
3. В секретах хостинга задайте `SIJK_CHECK_GOOGLE_CREDENTIALS_JSON` — полный JSON ключа сервисного аккаунта. **Не коммитьте ключ в GitHub**.
4. Опционально задайте `SIJK_CHECK_SPREADSHEET_ID` (по умолчанию используется база SIJK SYSTEM).
5. Установите зависимости из `requirements.txt`.

Чтение выполняется через Google Sheets API с read-only scope. Данные кэшируются на 120 секунд. Если авторизация не настроена или API недоступен, бот не выдает «Нет информации».

## Настройка Discord

В тестовом сервере:

1. Создайте публичный канал и закрытый канал рассмотрения. Проверьте права закрытого канала.
2. Вызовите `/check_setup`, выберите оба канала и роль `byba` (по ID роли).
3. В публичном канале вызовите `/check_panel`.
4. Проверьте `/check riot_id:...`, кнопки, создание и дополнение заявки, закрытый просмотр и решения.

Решения могут принимать **только** обладатели указанной роли в канале рассмотрения. Команды настройки доступны администраторам. Публичный результат доступен только в указанном канале.

## Пока не готово

- При одобрении карточка переводится в `approved_pending_sync`, **не записывается в Google Sheets**. Для полного одобрения нужна форма оценки/статуса и безопасная синхронизация.
- Результаты проверки и заявки не тестировались в реальном Discord/на Bothost.
- История Riot ID и идентификация игрока после переименования — отдельная будущая функция.
- Необходимо проверить поведение при большом числе заявок, сбоях сети и перезапуске бота.

## Безопасность

SQLite-файл должен сохраняться на постоянном томе хостинга, иначе заявки могут пропасть при пересоздании контейнера. Не публикуйте ключ сервисного аккаунта и приватные доказательства. Перед объединением с main проверьте резервную копию базы и тестовый запуск.
